# Overseas Compliance Style

Use this reference before drafting entries for the overseas compliance column.

海外合规条目不要写成“海外法规摘要”。先判断事件层级，再决定描述强度：

- 已生效法规、监管处罚、法院判决：可以作为确定事实写入，但要说明是否仍可上诉、是否一审、是否只是暂停令或部分撤销。
- 监管调查、草案、倡议回应、政府表态：只写“启动调查”“拟出台”“计划对话”“尚未确定”，不得写成已经新增义务。
- 媒体报道：必须保留“据媒体报道”“有消息称”等限定，并优先补一条官方或权威来源；没有官方来源时，解读要降一级。

事实段写法：

- 第一句交代国家/地区、机构或法院、事件性质和对象，例如罚款、判决、倡议回应、拟议禁令。
- 第二句写核心事实，优先放数字、金额、条文、受影响人数、整改要求、适用日期。
- 第三句说明法律状态或后续安排，例如一审未终局、监管命令被部分撤销、年底前制定行业准则、草案仍在征求意见。
- 对游戏高度相关的海外事件，可以在事实段点出玩法、功能或运营动作，例如 Loot Box、停服、年龄验证、数据跨境访问。

解读段写法：

- 先回溯同一事件的前序节点，不要泛泛说“近年来”。例如“该案始于 2021 年调查，2025 年作出处罚，本次判决处理的是企业上诉”。
- 再横向补一个相近案例或同地区动向，用来说明监管关注点，而不是堆砌国家或机构。
- 最后落到公司动作，必须写成具体场景：境内研发/客服远程访问欧盟用户数据、停服通知和退款安排、抽卡概率与未成年人限制、后台权限和异常访问监测、年龄验证和家长控制。
- 如果事件还未形成硬性义务，结论应写“提前评估”“纳入产品生命周期管理”“准备证据材料”，不要写“立即整改”。

常用收束句式：

- `对于出海欧洲市场的游戏企业而言，即使数据存储于欧洲本地服务器，中国境内研发、运营、客服或风控团队的远程访问也可能构成 GDPR 意义上的数据传输。`
- `欧盟暂未新增“停服后继续运营”类强制义务，但游戏停运、服务器关闭及数字内容失效问题已进入消费者权益保护议程。`
- `若产品面向未成年人，应把年龄验证、家长控制、个性化广告限制和 Loot Box 机制放在同一套方案中评估。`
- `平台型产品发生数据泄露后，监管机构通常会同时检查安全措施、合法收集依据和调查配合情况。`
