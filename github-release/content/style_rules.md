# Style Rules

## 禁用句式

- 不是……而是……
- 制度链条：（用自然语言叙述政策来龙去脉，不用冒号+箭头）
- 本事项属于……不宜写成……（AI 自我纠偏口吻，删掉）

## 篇幅

- 政策描述：180—260 字
- 政策解读（短版）：220—360 字
- 政策解读（长版参考）：500—1000 字
- 罗列不超过 3 个顿号词组

## 新闻段信息密度

- 通报类条目：列出具体违规类型（逐项编号），不只用"涉及多个场景"概括。
- 整改类条目：注明整改期限（如"自通报之日起5个工作日内完成整改"）。

## 三个核心原则

1. **法条引用**：超链接+自然嵌入。正文最多一条法条名，不写编号和括号日期。
2. **合规变化**：描述"省了什么"，不描述合规类型的名称变化。
3. **单一推力**：对游戏公司的建议只保留一个核心判断方向，删旁支。
